# ГородСтрой: рекламный плакат A4, скидка 20%

| Файл | Что это |
|---|---|
| `ГородСтрой.svg` | Исходник для Illustrator: всё векторное, текст можно редактировать (шрифт Arial), объекты сгруппированы (SKY, CITY, CRANE, STREET, LOGO, HEADLINE, INFO_BAR) |
| `ГородСтрой.pdf` | Файл для печати: A4, полностью вектор, текст переведён в кривые |
| `ГородСтрой.png` | Превью, 300 dpi |

## Как сохранить в формате .ai

1. Создайте папку `Документы\Демоэкзамен` и скопируйте туда файлы.
2. Откройте в Illustrator: **Файл → Открыть → `ГородСтрой.svg`**. Монтажная область будет A4 (210×297 мм).
3. Выберите **Файл → Сохранить как → Adobe Illustrator (\*.AI)** и сохраните как `Документы\Демоэкзамен\ГородСтрой.ai`.

Телефон, сайт, адрес и сроки акции указаны для примера. Если в задании экзамена есть свои данные, замените их инструментом «Текст» (T).
