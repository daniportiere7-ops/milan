# ГородСтрой: рекламные плакаты

Путь на компьютере: `Documents/Дизайн/Колледж/4 курс/Журба/Демоэкзамен`.

```
Демоэкзамен/
├── Плакат 1 - Скидка 20/        «Скидка 20% на квартиры в новостройках»
│   ├── ГородСтрой_A4.ai          A4, 210×297 мм
│   ├── ГородСтрой_A4.pdf         то же для печати
│   ├── ГородСтрой_A4.png         300 dpi
│   ├── ГородСтрой_640x400.ai     баннер 640×400 px
│   ├── ГородСтрой_640x400.png
│   └── Исходники/                SVG с живым текстом и SVG с текстом в кривых
└── Плакат 2 - Выше не дороже/   ЖК «Высота»: «Выше — не дороже. Любой этаж по цене второго»
    ├── (те же файлы: A4 и 640×400)
    ├── Исходники/
    └── Шрифты/                   Montserrat (лицензия OFL, бесплатный)
```

Во втором плакате кнопочная панель лифта поднимается над облаками, как башня: кнопка 26 горит,
кнопка 2 отмечена, а стрелка между ними подписана «одна цена».

## Про файлы .ai

`.ai` открывается в Illustrator двойным щелчком. Внутри всё векторное, текст переведён в кривые, поэтому плакат выглядит одинаково на любом компьютере, даже если нужных шрифтов нет.

Файлы собраны без Illustrator, в PDF-совместимом формате `.ai`. Чтобы файл стал «родным» для Illustrator, откройте его и сделайте **Файл → Сохранить** (Cmd+S).

## Если нужно поправить текст

Откройте SVG из папки `Исходники` (без «_кривые» в имени). В нём текст редактируется инструментом «Текст» (T).

- Плакат 1 набран шрифтом Arial, он есть на любом Mac.
- Для плаката 2 сначала установите шрифты из папки `Шрифты`: двойной щелчок по каждому файлу → «Установить».

После правок сохраните через **Файл → Сохранить как → Adobe Illustrator (\*.AI)** поверх нужного `.ai`.

Телефон, сайт, адрес, название ЖК и сроки акции придуманы для примера. Если в задании экзамена есть свои данные, замените их.
