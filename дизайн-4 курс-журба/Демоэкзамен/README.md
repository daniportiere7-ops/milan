# ГородСтрой: рекламный плакат A4, скидка 20%

```
дизайн-4 курс-журба/
└── Демоэкзамен/
    ├── ГородСтрой.pdf            файл для печати: A4, вектор, текст в кривых
    ├── ГородСтрой.png            превью, 300 dpi
    └── Исходники/
        ├── ГородСтрой.svg        редактируемый исходник (текст живой, шрифт Arial)
        └── ГородСтрой_кривые.svg тот же макет, текст переведён в кривые
```

## Как получить ГородСтрой.ai

1. Распакуйте архив в `Документы`, чтобы получилось `Документы\дизайн-4 курс-журба\Демоэкзамен`.
2. Откройте Illustrator: **Файл → Открыть → `Исходники\ГородСтрой.svg`**. Монтажная область будет A4 (210×297 мм).
3. **Файл → Сохранить как → Adobe Illustrator (\*.AI)**, имя `ГородСтрой.ai`, папка `Демоэкзамен`.

Объекты в файле сгруппированы: SKY, CITY_FAR, CITY, CRANE, STREET, LOGO, HEADLINE, INFO_BAR.

Телефон, сайт, адрес и сроки акции указаны для примера. Если в задании экзамена есть свои данные, замените их инструментом «Текст» (T).
